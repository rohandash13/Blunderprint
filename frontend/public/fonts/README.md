# Archivo

`archivo-latin-wght-normal.woff2` is the normal-width Latin weight-variable Archivo v25 font distributed by `@fontsource-variable/archivo` 5.3.0. It was extracted unmodified from the npm package. Source: https://github.com/google/fonts/tree/main/ofl/archivo. Copyright belongs to The Archivo Project Authors; the bundled `OFL.txt` contains the license. The UI serves this file locally and does not contact Google Fonts.
