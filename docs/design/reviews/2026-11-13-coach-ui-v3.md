# Coach UI finish review

**Verdict: ready for PR review.** Production verification remains after merge. This is a self-review against the approved Club Wallchart contract, PRODUCT.md and craft floor; no unavailable reviewer agents were invoked.

## Findings and fixes

- The handoff's third polish batch was already committed as `a306656`. It provides clock examples with slips included in the fetch, normal landing heading leading, the phone wallchart gutter and whole-game scrolling, a tighter player header, mixed-kind-only rows and a decorative progress sheet.
- A difficulty request could complete after a newer request for the same player and overwrite the clock plate's examples. Regression tests were written first; effect cleanup now discards obsolete successes and failures. Selected levels still filter the fetched clock examples.
- At a 390px viewport the desktop whole-plate width formula rounded below one plate, collapsing focus content to zero width. A browser assertion reproduced this before the CSS fix. Phone focus now uses its full 358px content width with no horizontal page overflow.
- The short analysis screen let the mobile shell stretch its navigation header. Explicit `auto 1fr` grid rows keep the header compact.
- The desktop difficulty segmented control ended 12px short of the plate edge even though its scope text reached the edge. A failing browser assertion preceded the fix; both now end at x=1372 on a 1440px viewport. Phone controls retain their own stacked alignment.
- Archivo is now self-hosted with an OFL license and provenance, removing the Google Fonts request while preserving the chosen workhorse face.
